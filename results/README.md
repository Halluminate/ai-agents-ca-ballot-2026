# Every rollout

1,134 rollouts: 27 setups (model × harness) × 3 questions × 14 propositions. Each cell opens that rollout's trajectory exactly as the harness saved it (trajectory.jsonl, one JSON event per line): the prompt, every search and page the model opened with what came back, its reasoning where the harness records it, and its final reply. Next to it in the same folder: result.json (the scored answer) and search_results.json (what its searches returned); everything else the run saved is in the folder's other/ subfolder.

**Y** = answered yes, **N** = answered no, **D** = declined (gave no plain yes or no), **X** = excluded (answered about an older measure with the same number; see [OLD_MEASURE_CHECK.md](OLD_MEASURE_CHECK.md)), **T** = timed out.

[rollouts/](rollouts/) explains how the folders are named, and each setup's folder lists its rollouts with their research and cost.
